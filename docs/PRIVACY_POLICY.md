# Política de Privacidade

Este documento descreve como o sistema Panificadora Jardim PDV trata os dados coletados durante a operação do produto.

## Dados coletados
- Dados de acesso e autenticação.
- Informações de produtos, pedidos e vendas.
- Dados de operação necessários para o funcionamento do PDV.

## Finalidade
- Garantir o funcionamento do sistema.
- Registrar vendas e pedidos.
- Melhorar a experiência de uso e o suporte.

## Segurança
- Os dados são armazenados em ambiente controlado e com acesso restrito.
- Recomenda-se o uso de senhas fortes e controle de usuários.
